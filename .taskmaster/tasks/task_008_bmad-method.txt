### Dependencies: None

### Dependencies: 8.1

### Dependencies: 8.2

### Details:
Use Zod schema validation to check for required fields, valid date formats, and numeric ranges. Reject malformed proposals with error codes.

## 4. Confirm receipt and notify sender [pending]
### Dependencies: 8.3
### Description: Automatically send confirmation message to supplier upon successful parsing and validation.
### Details:
Trigger WhatsApp reply via API confirming receipt, including parsed summary for verification. Log confirmation status.

### Dependencies: 8.3
### Description: Insert validated proposal data into the database and link it to relevant entities (e.g., supplier, work).
