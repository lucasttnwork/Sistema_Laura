# Task ID: 7
# Title: Build Quotation Distribution System
# Status: pending
# Dependencies: 5, 6
# Priority: medium
# Description: Automate sending quotations to at least 3 suppliers per category via WhatsApp, with 24h deadline.
# Details:
Backend logic to select suppliers and send messages using Z-API or 360Dialog. Implement webhooks for responses. Store quotation data in database. Add automatic notifications.

# Test Strategy:
Trigger quotation distribution, verify WhatsApp messages sent, check database updates on responses.

# Subtasks:
## 1. Design and implement supplier selection logic [pending]
### Dependencies: None
### Description: Develop backend logic to select at least 3 active suppliers per material category based on performance and availability.
### Details:
Use Prisma to query suppliers by category and status. Prioritize suppliers with best performance history. Ensure fallback logic if fewer than 3 suppliers are available.

## 2. Integrate WhatsApp messaging via Z-API or 360Dialog [pending]
### Dependencies: 7.1
### Description: Set up API integration to send automated quotation messages to selected suppliers via WhatsApp with 24h deadline notice.
### Details:
Configure Z-API or 360Dialog credentials. Format message templates with dynamic fields (request ID, deadline, materials). Handle rate limits and delivery confirmations.

## 3. Implement webhook endpoint for supplier responses [pending]
### Dependencies: 7.2
### Description: Create secure webhook endpoint to receive and validate incoming WhatsApp messages from suppliers.
### Details:
Validate message origin using webhook signatures. Parse sender ID and message content. Route responses to Task 8 for further processing.

## 4. Store quotation metadata and track deadlines [pending]
### Dependencies: 7.1, 7.2
### Description: Persist quotation distribution records with timestamps, supplier IDs, and 24h deadline in database.
### Details:
Create Prisma schema for quotation tracking. Automatically calculate and store deadline (current time + 24h). Index by status and deadline for efficient querying.

## 5. Add automatic deadline notifications and escalations [pending]
### Dependencies: 7.4
### Description: Implement scheduled job to send reminder notifications to suppliers approaching deadline and escalate if no response.
### Details:
Use cron or queue system to check for quotations with <4h remaining. Send WhatsApp reminder. If deadline passes without response, notify internal team and update status.
