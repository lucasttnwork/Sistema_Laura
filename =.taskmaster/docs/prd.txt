BMAD PRD - Sistema Laura

1. Visão Geral
- Objetivo: Consolidar auditoria completa, revisão técnica e plano de entrega para colocar o Sistema Laura em produção com qualidade, seguindo o BMAD-METHOD.
- Escopo inicial: Inventário do que já foi feito (API, Dashboard, Prisma, Scripts), lacunas, riscos, rotas de correção e plano de testes com QA (Test Architect).

2. Contexto Atual (Brownfield)
- Monorepo com apps/api (Node/TypeScript), apps/dashboard (Next.js), packages (prisma, observability, shared, whatsapp-zapi).
- Problemas recorrentes: falhas de execução, inconsistências de build, falta de rastreabilidade e testes insuficientes.
- Referência metodológica: BMAD-METHOD (Guiding Principles, Brownfield, Enhanced IDE Workflow, Test Architect).

3. Metas
- Auditoria técnica completa (infra, código, dependências, segurança, CI/CD).
- Rastreabilidade ponta-a-ponta (requirements → tasks → code → tests → releases).
- Qualidade com gates: risco, design de testes, NFR, revisão e aprovação antes de merge/deploy.
- Entrega gradual até produção com monitoramento e rollback seguro.

4. Entregáveis
- Catálogo do estado atual (inventário por módulo, riscos e dívidas).
- Plano de remediação priorizado com marcos e critérios de aceite.
- Test strategy com Test Architect: risco, cases, cobertura, regressão, NFR.
- Pipeline de qualidade (pré-merge, pré-release, pós-deploy) com evidências.

5. Requisitos (alto nível)
- API estável com autenticação, logs e métricas básicas.
- Dashboard acessível, com login e páginas principais estáveis.
- Banco (Prisma) com migrações consistentes e seeds reproduzíveis.
- Observabilidade mínima (healthcheck, logs estruturados, tracing opcional).
- Scripts de verificação (integridade, smoke tests) e CI local.

6. Abordagem BMAD
- Brownfield-first: documentar antes de refatorar.
- Test Architect em cada etapa: *risk*, *design*, *trace*, *nfr*, *review*, *gate*.
- Templates e artefatos versionados no repositório.

7. Restrições
- Manter compatibilidade com o que já roda.
- Evitar refatorações amplas sem mitigação e testes.

8. Critérios de Aceite
- Lista de riscos tratada (ou mitigada) com evidências.
- Cobertura mínima de smoke e rotas críticas.
- Deploy de staging concluído com checklist BMAD e rollback testado.

9. Roadmap Inicial
- Semana 1: Inventário + riscos + PRD validado.
- Semana 2: Remediações críticas + testes + observabilidade mínima.
- Semana 3: Stabilização + staging + validação QA (gate).
- Semana 4: Go/No-Go para produção.
